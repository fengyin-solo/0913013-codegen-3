## 项目管理

### 创建新项目

1. 点击左侧菜单「项目管理」
2. 点击右上角「新建项目」按钮
3. 填写项目信息：
   - **项目名称**: 必填，建议使用工区名称
   - **项目描述**: 可选，填写项目背景和目的
4. 点击「保存」

### 管理项目成员

1. 在项目列表中找到目标项目
2. 点击「数据管理」按钮
3. 在弹出窗口中可以：
   - 查看已有地震数据
   - 上传新的地震数据
   - 查看数据处理状态

### 项目角色说明

| 角色 | 权限 |
|------|------|
| **所有者 (Owner)** | 完全控制，可管理成员和删除项目 |
| **编辑者 (Editor)** | 可上传、编辑数据，创建标注和测量 |
| **查看者 (Viewer)** | 只能查看数据和已有标注 |

### 批量处理（多选）

项目列表支持勾选多个项目后一次性处理。

1. 勾选列表左侧复选框（可跨页勾选），列表上方会显示已选数量与批量操作按钮。
2. 选择批量操作：
   - **批量分配协作成员**：选择一位成员和角色（查看者/编辑者/所有者），所选项目会逐个把该成员加入协作。
   - **批量转移数据体**：选择一个目标项目，所选项目下的全部地震数据体（切片、标注随数据体一起）会逐个转移到目标项目；井数据仍保留在原项目。
3. 系统逐条独立执行并实时显示每条的成功/失败结果：
   - 成功：绿色对勾，并给出处理摘要（如转移了几个数据体）。
   - 失败：红色叉号并说明原因，可点该条右侧「重试此条」单独重试，也可在结束后「重试全部失败项」。
4. 执行过程中可随时「停止后续处理」或关闭窗口：**已经处理成功的项目不会回退**，未处理的项目标记为已取消，之后重新勾选再执行即可。

常见失败原因与处理方式：

| 失败原因 | 说明 | 处理方式 |
|----------|------|----------|
| 成员已是项目成员 | 该成员已在项目中，重复添加无意义 | 如需变更角色，在成员管理中调整；不需要变更则忽略 |
| 同名数据体冲突 | 目标项目下已存在同名数据体，消息中会列出冲突名称 | 在源项目或目标项目中重命名后，对该条点「重试此条」 |
| 目标项目不可用 | 你没有目标项目的编辑权限，无法转入 | 请目标项目所有者授予编辑者权限，或换一个目标项目 |
| 项目不存在（已被删除） | 提交前该项目已被其他用户删除 | 该条无法处理，关闭后列表会自动刷新 |
| 权限不足 | 分配成员需要所有者权限，转移数据体需要源/目标项目的编辑者权限 | 联系项目所有者操作 |

批量处理完成后，所有入口的归属会同步变化：新成员登录后即可在其项目列表看到这些项目；数据体转移后，源项目的数据列表中不再出现，目标项目的数据列表中可以查看与打开。

单条创建、编辑、删除项目的操作方式保持不变。

## 地震数据上传

### 支持的数据格式

- **SEG-Y**: 标准地震数据格式 (.sgy, .segy)
- 最大文件大小: 10 GB

### 上传步骤

1. 进入「项目管理」页面
2. 点击目标项目的「数据管理」按钮
3. 填写数据信息：
   - **数据名称**: 必填
   - **描述**: 可选
4. 点击「选择SEG-Y文件」
5. 选择本地SEG-Y文件
6. 点击「上传」按钮
7. 等待上传和处理完成

### 数据处理状态

| 状态 | 说明 |
|------|------|
| ![uploading](https://img.shields.io/badge/-上传中-orange) | 文件正在上传 |
| ![processing](https://img.shields.io/badge/-处理中-blue) | 系统正在解析SEG-Y头信息 |
| ![ready](https://img.shields.io/badge/-就绪-green) | 数据已准备好，可以查看 |
| ![error](https://img.shields.io/badge/-错误-red) | 处理失败，请检查文件格式 |

### 处理时长参考

| 文件大小 | 预计处理时间 |
|----------|-------------|
| < 1 GB | 几秒 |
| 1-10 GB | 30秒 - 2分钟 |
| 10-100 GB | 2-10分钟 |
| > 100 GB | 10分钟以上 |

## 三维可视化

### 进入查看器

1. 在「数据管理」窗口中找到就绪的数据
2. 点击「查看」按钮
3. 系统将加载三维可视化视图

### 视图操作

#### 旋转视图
- **鼠标左键拖拽**: 绕中心点旋转
- **快捷键**: 按住 `Alt` + 左键拖拽

#### 平移视图
- **鼠标中键拖拽**: 平移视图
- **快捷键**: 按住 `Shift` + 中键拖拽

#### 缩放视图
- **鼠标滚轮**: 放大/缩小
- **快捷键**: `+` 放大, `-` 缩小

#### 重置视图
- 点击工具栏 🏠 按钮
- 快捷键: `R`

### 显示设置

#### 背景切换
1. 打开右侧「控制面板」
2. 展开「显示设置」
3. 选择「深色」或「浅色」背景

#### 坐标轴和网格
- 在「显示设置」中可以开关坐标轴和网格显示

### 体绘制 (Volume Rendering)

体绘制功能可以直接将三维数据体渲染成半透明的立体图像，帮助快速识别异常体。

#### 启/健体绘制
1. 打开右侧「控制面板」
2. 展开「体绘制」
3. 点击「启用体绘制」开关

#### 调整参数
- **透明度**: 调节体绘制的整体透明度
- **采样率**: 影响渲染质量和性能（高采样率更清晰但更慢）

*提示: 体绘制对GPU性能要求较高，低配置电脑建议关闭此功能以获得更好的交互体验。*

## 切片分析

切片分析是地震解释中最常用的功能，支持三种类型的切片：

| 切片类型 | 说明 |
|---------|------|
| **Inline** | 沿主测线方向的垂直切片 |
| **Crossline** | 沿联络测线方向的垂直切片 |
| **深度切片** | 沿时间/深度方向的水平切片 |

### 显示切片

1. 打开右侧「控制面板」
2. 展开「切片控制」
3. 找到要显示的切片类型
4. 点击右侧的眼睛图标开关

### 调整切片位置

#### 使用滑块
1. 在控制面板中拖动「切片索引」滑块
2. 视图中的切片位置会实时更新

#### 精确输入
1. 点击滑块旁边的数字标签
2. 输入具体的切片号

### 调整切片显示

#### 不透明度
- 拖动「不透明度」滑块调整切片的透明程度
- 100% = 完全不透明，0% = 完全透明

#### 颜色映射 (Colormap)
系统提供多种颜色映射方案：

| 色标 | 适用场景 |
|------|---------|
| **地震波色标 (Seismic)** | 标准地震显示，蓝色负振幅，红色正振幅 |
| **灰度 (Gray)** | 黑白显示，适合打印 |
| **彩虹 (Rainbow)** | 多色显示，突出数值变化 |

#### 数值范围
- 默认使用数据的全局最小/最大值
- 可以手动设置数值范围来增强特定区间的显示效果

### 切片浏览技巧

1. **快速扫查**: 按住滑块快速拖动，浏览整段数据
2. **精细对比**: 同时显示Inline和Crossline切片，观察交点处特征
3. **层位追踪**: 固定深度切片，逐步移动观察层位变化

## 空间测量

系统支持三种测量模式：距离、面积和体积。

### 距离测量

1. 点击工具栏 📏 「测量」按钮
2. 选择「距离」模式
3. 在三维视图中点击两个点
4. 测量结果会显示在视图上和状态栏中

**结果单位**: 米 (m)

### 面积测量

1. 选择「面积」测量模式
2. 依次点击至少3个点形成多边形
3. 点击最后一个点后自动计算面积

**结果单位**: 平方米 (m²)

### 体积测量

1. 选择「体积」测量模式
2. 依次点击至少4个点形成多面体
3. 系统自动计算封闭体积

**结果单位**: 立方米 (m³)

### 测量操作

- **清除测量点**: 点击工具栏 🔄 按钮
- **切换测量模式**: 直接点击对应的模式按钮
- **取消测量**: 点击其他工具按钮（如旋转）

## 数据标注

标注功能允许您在地震数据上标记感兴趣的区域和解释结果。

### 标注类型

| 类型 | 说明 | 用途 |
|------|------|------|
| **点 (Point)** | 单点标记 | 标记异常点、井点位置等 |
| **线 (Line)** | 折线标记 | 标记断层、层位线等 |
| **多边形 (Polygon)** | 闭合区域 | 标记砂体范围、有利区带等 |
| **层位 (Horizon)** | 专业层位解释 | 追踪地层界面 |
| **断层 (Fault)** | 专业断层解释 | 标记断裂系统 |

### 创建标注

1. 点击 ✏️ 「标注」工具
2. 在视图中点击放置标注点
3. 完成后按 `Enter` 或双击结束
4. 在弹出窗口中填写标注信息

### 管理标注

所有标注会保存在系统中，可以：
- 显示/隐藏特定标注
- 编辑标注属性
- 删除不需要的标注
- 导出标注数据（JSON/CSV格式）

## 常见问题

### Q: 为什么上传的SEG-Y文件处理失败？

**可能原因:**
1. 文件格式不正确，不是标准的SEG-Y格式
2. 文件损坏
3. 数据体维度异常

**解决方法:**
1. 使用SeisWare、Kingdom等专业软件验证文件
2. 尝试重新导出SEG-Y文件
3. 查看错误信息中的详细描述

### Q: 三维视图显示卡顿怎么办？

**优化建议:**
1. 关闭体绘制功能
2. 降低浏览器标签页数量
3. 使用Chrome或Edge浏览器
4. 确保电脑显卡驱动已更新
5. 降低浏览器窗口大小

### Q: 切片加载很慢是什么原因？

**可能原因:**
1. 网络带宽不足
2. 数据体过大
3. 服务器负载高

**解决方法:**
1. 等待预加载完成后再操作
2. 使用本地部署而非远程访问
3. 避免短时间内频繁切换切片

### Q: 如何导出截图和数据？

**截图:**
- 使用浏览器截图功能 (`Ctrl + Shift + S` in Chrome)
- 或使用系统截图工具

**数据导出:**
- 标注数据可在标注管理中导出
- 切片图像可右键另存为
- 原始数据请联系管理员

### Q: 支持哪些浏览器？

**推荐:**
- Google Chrome 90+ ✅
- Microsoft Edge 90+ ✅
- Mozilla Firefox 88+ ✅

**不推荐:**
- Safari (WebGL性能较差)
- Internet Explorer (完全不支持)

### Q: 数据安全如何保障？

- 所有数据存储在您部署的服务器上
- 用户密码使用bcrypt加密存储
- 支持HTTPS加密传输
- 详细的访问日志记录
- 可配置IP白名单限制访问
